# AGENTS.md — Rust core (`src-tauri/`)

Applies on top of the root [AGENTS.md](../AGENTS.md). Deep reference: `docs/ARCHITECTURE.md` §3-§7, §9, §10.
**Run cargo from this directory** (`.cargo/config.toml` sets `TS_RS_EXPORT_DIR` and `TS_RS_LARGE_INT` relative to it).

## Module responsibilities

- `commands/` only parses arguments, calls a service and maps errors; no logic. `blocking()` runs local file I/O,
  keychain and parsing off the async runtime. `names.rs` is the single command list (also `include!`d by `build.rs`).
- `ssh/` dialing, hop chaining (`connect`), host-key handler, auth (`auth`, budget/ordering rules in ARCHITECTURE
  §5.6), key discovery (`keys`), owner-verified agent (`agent`), `PromptBroker` (`prompt`), remote identity probe,
  `shellquote` (the only place that builds shell text from data).
- `session/` one supervisor task per session: state machine, auto-reconnect, host-key pins, `HopSecrets` (`ssh/auth.rs`),
  live bookmark edits (`live`). Terminals and transfers are owned by their session.
- `terminal/` reader (never stops draining) + pump, pure `flow.rs` backlog/ack state. `sftp/` RawSftpSession
  wrapper, bounded listing, `save` (atomic/in-place/conflict), `transfer` (1 to 64 concurrent per session, default 3, `.part`,
  provenance mark), `throttle`, `drops`.
- `sshconfig/`, `known_hosts/` own parsers/writers (do not swap in russh's). `storage/` JSON files, atomic, 0600,
  validate-on-load, migrations. `platform/` is the only way to open local files (`local_path` allowlist + `file_trust`
  on the opened handle) and holds all Win32 security code. `window.rs`, `quit.rs`, `app_menu.rs`, `e2e.rs`.
- `ipc/dto.rs` holds every DTO. Outbound types derive `Serialize + TS`, inbound `Deserialize + TS`; secrets are
  `Secret<T>` (inbound only, zeroized, `Debug` masked). Keep the list of secret-bearing fields exhaustive.

## Adding or changing a command end to end

1. Add the name to `src/commands/names.rs` and the function (`#[tauri::command]`, `Result<T, AppError>`) in the
   right `commands/*.rs`; register it in `app_commands!` in `commands/mod.rs`.
2. Add `"allow-<name-with-dashes>"` to `capabilities/main.json`. `commands::acl_tests` fails until handler,
   manifest and capability agree. `permissions/autogenerated` is generated and git-ignored.
3. New or changed DTOs go in `ipc/dto.rs` (`#[ts(export)]`, `camelCase`, tagged enums). Run
   `npm run bindings` from the root (= `cargo test --locked export_bindings` here) and commit `../src/ipc/bindings/`.
4. New error cases: add an `ErrorCode` variant in `error.rs` (params camelCase), map it in the mapping functions,
   and add `errors.<code>` to `../src/i18n/locales/en/translation.json` and the `uk` file (Vitest tests check completeness and parity).
5. Frontend: `Backend` interface, `TauriBackend`, `MockBackend`, and the row in `src/ipc/tauriBackend.test.ts`.
6. Tests (below), then update `docs/ARCHITECTURE.md` §4.2 and any behaviour notes.

## Testing patterns

- Unit tests live next to the code (`#[cfg(test)] mod tests`); `unwrap()` is allowed in tests only.
- Services take small `EventSink` traits instead of Tauri types so tests use in-memory sinks. Use
  `#[tokio::test(start_paused = true)]` for timers (prompt timeouts, backoff).
- Integration tests (`tests/it_*.rs`, feature `it`) run against the Docker sshd (`tests/sshd/`); the harness in
  `tests/support` starts the fixtures. `it_resilience` pauses the target and regenerates host keys, so it is a
  separate serialised binary. `flow_memory` and `listing_memory` assert heap bounds with a counting allocator.
- Windows file-trust and path tests must use private temp dirs (`platform::test_support::private_tempdir`); `%TEMP%` can
  carry inheritable ACEs the trust checks correctly reject.
- Test keys in `tests/fixtures/keys/` are throwaway and must keep the `shellfin-test` comment; never add real keys.
- Hostile-input cases are mandatory for parsers, path handling, save/transfer logic and anything shown to the user.

## Rules that bite

- Lints deny `unwrap_used`, `expect_used`, `std::process::Command` (`clippy.toml`) and, in `ssh/`, `sftp/`,
  `sshconfig/`, `known_hosts/`, slice indexing. `panic = "unwind"` is required (supervisors contain panics).
- Never log secrets, terminal data, file contents or kbd-int answers. Panic hook logs the location only.
- Remote paths: POSIX only, absolute, no NUL, <= 4096 bytes; refuse U+FFFD paths for file operations.
- `e2e` is a test-only feature that redirects all user state; it must never reach a release build (see `e2e.rs`,
  `build.rs`, CI marker checks).
- russh is pinned with `=`; re-run the integration suite and re-check ARCHITECTURE §2.3 when upgrading.
- Do not use the Windows OpenSSH agent with unconstrained key adds; keep the owner checks for agent endpoints.
