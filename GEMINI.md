# Shellfin: instructions for Gemini CLI

Shellfin is a cross-platform desktop SSH client (Tauri 2, Rust/russh, React/TypeScript). The canonical project
instructions are in `AGENTS.md`; read it first. `src-tauri/GEMINI.md` and `src/GEMINI.md` import the area files
`src-tauri/AGENTS.md` and `src/AGENTS.md`, which Gemini CLI would not find on its own. The deep reference is
`docs/ARCHITECTURE.md`.

@./AGENTS.md

The five rules that matter most:

1. Every user-facing string goes through i18n (`t("key")` + `translation.json` for `en` and `uk`, see `docs/i18n-glossary-uk.md`), no literals.
2. `src/ipc/bindings/**` is generated by ts-rs: never edit it; change the Rust DTO and run `npm run bindings`.
3. The webview never passes local filesystem paths; show remote/server text only via `displayName`, `displayPath`
   or `displayServerText`; no `innerHTML`; keep the CSP strict and `freezePrototype` on.
4. Least-privilege ACL: every new command needs a `names.rs` entry, a capability permission and a passing ACL test.
5. Security-sensitive code needs tests; run all gates from AGENTS.md before finishing; Conventional Commits.
